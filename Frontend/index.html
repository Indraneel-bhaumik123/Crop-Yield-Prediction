Prospective Model Selection Rationale

Under rigorous out-of-time evaluation (year 2013 holdout), Distance-Weighted KNN Regressor demonstrated superior generalization fidelity across all three seasonal regimes (R² = 0.9380 on Kharif, 0.9636 on Rabi, and 0.9642 on Seasonal). Inverse-distance weighting effectively leverages localized agro-climatic analogues while filtering extreme outliers. XGBoost Regressor was verified as the strongest tree-based candidate (R² > 0.90 across all seasons).

Executive Agronomic Summary

This automated report synthesizes 24 years of historical agricultural production records (1990–2013) across 100+ countries and 10 staple crop varieties. The system utilizes machine learning to provide prospective seasonal forecasts tailored to Kharif, Rabi, and Whole-Year cropping systems.

Key Recommendations:

  • Precision Input Management: Pesticide application exhibits diminishing returns above 2,500 tonnes. Targeted chemical deployment maintains yield ceilings while reducing input expenditure.
  • Thermal Adaptation: Winter crops (wheat) exhibit steep yield declines when average growing temperatures exceed 24°C. Adjust sowing dates to match winter thermal windows.

About AgriYield

Methodological Architecture

AgriYield is an end-to-end scientific machine learning system engineered to predict agricultural crop yields under seasonal climatic variability.

  • Hierarchical Prediction Logic: Season → Continent → Country → Crop → Meteorological Inputs → Yield Estimation.
  • Time-Aware Train-Test Split: Models were trained on historical records (1990–2012) and evaluated strictly on future holdout data (2013) to ensure genuine prospective capability.
  • Robust Preprocessing: OneHotEncoder with unknown handling for nominal geography and StandardScaler for numerical environmental features.
  • Full-Stack Architecture: FastAPI REST Backend, SQLite database with SQLAlchemy ORM, JWT Bearer Token Security, and Interactive HTML5/CSS3/JavaScript Frontend.
